# EquipIT - Vue d'ensemble du corrigé

La solution conserve le périmètre guidé du projet : consultation des équipements, emprunt, retour et intégration d'un client web.

## Compétences couvertes

- POO et responsabilité unique.
- Service métier séparé du contrôleur.
- Injection de dépendances par constructeur.
- Persistance avec Spring Data JPA et SQLite.
- DTO et validation Jakarta.
- Gestion d'erreurs et codes HTTP.
- Tests unitaires JUnit 5 / Mockito.
- Consommation d'une API REST depuis React.
